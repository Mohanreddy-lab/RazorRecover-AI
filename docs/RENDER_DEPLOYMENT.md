# Render Deployment

## Deploy

1. Push the repository to GitHub.
2. In Render, choose **New** -> **Blueprint**.
3. Select the `Mohanreddy-lab/RazorRecover-AI` repository.
4. Render reads `render.yaml` and creates the web service plus a persistent disk mounted at `/data`.
5. Enter the secret values marked `sync: false` during setup.

The included Dockerfile builds the React client and bundled Express server. Render provides `PORT`; the service listens on it automatically.

## Required values

Set these in the Render Environment tab:

```text
APP_URL=https://YOUR-RENDER-DOMAIN.onrender.com
RAZORPAY_KEY_ID=rzp_test_or_live_key
RAZORPAY_KEY_SECRET=your_server_secret
RAZORPAY_WEBHOOK_SECRET=your_webhook_secret
AUTH_ADMIN_EMAIL=admin@example.com
AUTH_ADMIN_PASSWORD=your_admin_password
AUTH_MERCHANT_EMAIL=merchant@example.com
AUTH_MERCHANT_PASSWORD=your_merchant_password
```

`AUTH_SESSION_SECRET` is generated by the Blueprint. Never commit these values.

## Razorpay webhook

After Render creates the HTTPS domain, configure Razorpay Dashboard -> Webhooks with:

```text
https://YOUR-RENDER-DOMAIN.onrender.com/webhook/payment.failed
```

Subscribe to `payment.failed` and use the exact same webhook secret as `RAZORPAY_WEBHOOK_SECRET`.

## Verify

```text
https://YOUR-RENDER-DOMAIN.onrender.com/api/health
https://YOUR-RENDER-DOMAIN.onrender.com/checkout
```

Use the admin credentials for `/admin` and merchant credentials for `/merchant`.

## Scaling note

The persistent disk makes this a single-instance deployment. Do not add multiple web instances while using SQLite. Migrate the store to PostgreSQL before horizontal scaling.
